# Changelog

## 2.3.1

- Adds VCV Library URLs, the Rack40 support address, and VCV Rack 2.6.6 as the
  minimum supported version.
- Links module descriptions to the official ZOIA documentation.
- Expands installation, troubleshooting, and first-patch instructions.

## 2.3.0

- Synchronizes 740 ZOIA configurations and panel layouts, including firmware
  5.40 MIDI Pitch Bend Out and MIDI Pressure Out modules.
- Adds disconnect monitoring and starts-muted Live Control behavior.
- Preserves sequencer banks, portable presets, cable strengths, and browser /
  native exchange data.
- Adds Pushbutton Live MIDI setup with bounded press/release behavior.
- Clearly labels Rack40 modules **ZOIA HARDWARE REQUIRED**.

See the packaged `CHANGELOG.md` for complete technical notes and deferred work.
