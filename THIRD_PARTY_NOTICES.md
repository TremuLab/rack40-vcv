## VCV Rack SDK

Rack40 is built as a VCV Rack plugin using the VCV Rack SDK. The SDK is a
separate build dependency and is not redistributed in the Rack40 package.

## ZOIA module metadata

The canonical Rack40 module registry was generated in part from the ZOIA
module index maintained by the `zoia_lib` project, including work from the
meanmedianmoge project and Sheoak fork, then extended and corrected by Rack40.
`zoia_lib` is GPL-3.0 licensed. Rack40's generated registry and the complete
source inputs used by the VCV plugin are included in the source release.
